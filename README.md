# CalculateHub

CalculateHub, modern ve kullanıcı dostu bir arayüze sahip, çeşitli hesaplama ihtiyaçlarını karşılamak üzere tasarlanmış bir iOS hesap makinesi uygulamasıdır. Standart hesaplamaların yanı sıra, üniversite öğrencileri için özel fonksiyonlar ve yapay zeka destekli özellikler sunar.

## Özellikler

- **Modern Arayüz:** Sade, sezgisel ve özelleştirilebilir bir kullanıcı deneyimi.
- **Standart Hesap Makinesi:** Dört temel aritmetik işlem ve diğer bilimsel fonksiyonlar.
- **Üniversite Fonksiyonları:** Üniversite öğrencilerinin ihtiyaçlarına yönelik özel matematiksel hesaplamalar.
- **Yapay Zeka Entegrasyonu:** Karmaşık problemler için yapay zeka destekli çözümler ve öneriler.
- **Özelleştirilebilir Öğeler:** Uygulama içinde kullanabileceğiniz özel ikonlar ve geçiş butonları.

## Kullanılan Teknolojiler

- **Swift:** Projenin ana programlama dili.
- **SwiftUI:** Kullanıcı arayüzü tasarımı ve yönetimi.
- **Xcode:** Geliştirme ortamı.

## Kurulum

Projeyi yerel makinenizde çalıştırmak için aşağıdaki adımları izleyin:

1.  Bu repoyu klonlayın:
    ```bash
    git clone https://github.com/kullanici_adiniz/CalculateHub.git
    ```
2.  Proje dizinine gidin:
    ```bash
    cd CalculateHub
    ```
3.  Projeyi Xcode ile açın:
    ```bash
    open CalculateHub.xcodeproj
    ```
4.  Bir simülatör veya gerçek bir cihaz seçerek projeyi çalıştırın (▶ butonu).

## Katkıda Bulunma

Katkılarınız projeyi daha iyi hale getirmemize yardımcı olur. Katkıda bulunmak isterseniz, lütfen bir "pull request" açın. Hata bildirimleri ve özellik önerileri için "Issues" bölümünü kullanabilirsiniz.

1.  Projeyi "Fork" edin.
2.  Kendi özelliğiniz için yeni bir dal oluşturun (`git checkout -b ozellik/yeni-ozellik`).
3.  Değişikliklerinizi "commit" edin (`git commit -am '''Yeni bir özellik eklendi'''`).
4.  Dalınızı "push" edin (`git push origin ozellik/yeni-ozellik`).
5.  Bir "Pull Request" açın.
